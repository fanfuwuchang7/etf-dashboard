📌 操作标签：🟢加仓=相对低位+资金流入，左侧分批；🔵网格=震荡区间分3档高抛低吸；🟡持有=趋势跟随；🔴止损=破均线或短期超跌，参考止损价离场。
📌 大盘择时：强势🟢满仓(100%,3只) / 中性🟡半仓(50%,2只) / 弱势🔴防御(20%,1只)。
📌 三重风控：①价格站上20日均线 ②均线向上 ③3日跌幅≤5%。止损参考=20日线(或-5%硬止损)。
